"The Vacuum's Alibi: One Line, 200 Characters".

`main.py` writes a single line — the funniest one-line excuse a robot vacuum
can give for missing a spot, 200 characters or fewer — to `/output/entry.txt`:

> I scanned it twice. It was not dust, it was a crumb with a family, and I do not break up families.

(98 characters, one line.)

Run it with `python3 main.py`.
